## About the Repo

This repository contains a Python-based Text User Interface (TUI) game centered around the theme of cotton harvesting. The game simulates the experience of running a cotton farm, how fun!

## Game Overview

In Cotton Farming Simulator, you step into the shoes of a humble cotton farmer. Your goal is to plant, grow, and harvest cotton to maximise profits to pay child support for you ex-wife Linda.

**NOTE:** The current build does not include your ex-wife Linda.

## Installation

To run the game on your local machine, follow these steps:

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/dontmindme250/cotton-farming-sim.git
   cd cotton-farming-simulator
   ```

2. **Run the Game:**
   ```bash
   python main.py
   ```
